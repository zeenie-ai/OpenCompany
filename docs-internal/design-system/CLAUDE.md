# Prototype instructions

These rules apply to this reference bundle's prototypes. For production,
`client/src/themes/`, existing React primitives, root contributor guidance
and current frontend/theme docs take precedence. In particular, shipped
Atomic display roles and modal effects are intentional product behavior.

- Use properly readable fonts in all designs. Decorative/display theme fonts (blackletter, stencil or pixel faces, for example) may appear only as small specimens when documenting a theme — never on UI copy, buttons, labels, headings, or body text. UI copy always uses the readable stack: Geist for words, JetBrains Mono for machine voice, or each theme's readable body font.
- Avoid hard-to-read styles generally: no extreme letter-spacing on long text, no low-contrast text on tinted fills.
