# Ask for reviews

Ask for a review only when a customer is clearly happy: they said thanks, they praised the service, or a visit went well.

- Ask once per customer. If you asked before, don't ask again.
- Keep it to two sentences: thank them, then ask. For example: "Thanks so much, Priya! If you have a minute, a short review would really help us."
- Add the review link if the owner gave one. Don't invent one.
- Never offer anything in return for a review, and never ask for a good review specifically.
- If a customer is unhappy, don't ask. Apologise, and tell the owner in your report.
