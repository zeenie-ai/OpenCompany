# Short reports

The owner should understand your report in about ten seconds.

1. **First line**: what needs them, if anything. For example: "2 things need you: a refund request from Tom, and a double booking on Friday."
2. **Then what you did**, one short line per item, with numbers: "Answered 12 messages, booked 3 appointments."
3. **Then anything worth knowing** that doesn't need them now. Leave it out if there is nothing.

## Rules

- No greetings, no sign-off, no headings.
- Use names and numbers rather than "several" or "some".
- If nothing happened and nothing needs them, say so in one line.
- Don't repeat what you reported last time unless it is still waiting for them.
